# CamRent PH Remotion Opener

Intro opener videos for CamRent PH using the current app colors, card language, compact product/store surfaces, and owner dashboard concepts.

Compositions:

- `CamRentPHDesktopIntro` - 1920x1080 landscape opener.
- `CamRentPHMobileIntro` - 1080x1920 vertical opener.

Useful commands:

```bash
npm run studio
npm run still:desktop
npm run still:mobile
npm run render:desktop
npm run render:mobile
```

The video points viewers to `https://camrentph.vercel.app`.
